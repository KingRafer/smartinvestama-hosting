# SmartInvestama Hosting

File-file untuk hosting Smart AI / SmartInvestama (landing page + API live).

- `api/live.php` — proxy ke Google Apps Script (live accounts)
- `api/api_v2/` — endpoint alternatif berbasis file JSON (untuk EA MT5)
